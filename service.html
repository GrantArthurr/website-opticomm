Curriculum

Comprehensive Optical Learning

Kurikulum praktikum kami dirancang mencakup aspek fundamental penanganan serat optik, perancangan jaringan FTTH industri, hingga riset teknologi masa depan.

Fusion Splicing

Teknik penyambungan inti serat optik menggunakan panas (arc fusion) untuk menghasilkan sambungan permanen dengan redaman (loss) serendah mungkin.

Download Modul
OTDR Analysis

Analisis performa jaringan menggunakan Optical Time Domain Reflectometer untuk mendeteksi lokasi putus kabel (fiber break) dan mengukur total loss.

Download Modul
GPON Architecture

Perancangan arsitektur Gigabit Passive Optical Network (GPON) dari sentral (OLT) melewati ODC/ODP hingga ke perangkat pelanggan (ONT).

Download Modul
Device Configuration

Praktik langsung melakukan konfigurasi layanan Internet, VoIP, dan IPTV pada perangkat OLT ZTE/Huawei dan modem ONT.

Download Modul
Visible Light Comm.

Eksperimen komunikasi data nirkabel (Li-Fi) menggunakan modulasi cahaya lampu LED sebagai media transmisi data berkecepatan tinggi.

Download Modul
Free Space Optics

Implementasi transmisi data optik jarak jauh melalui media udara (atmosfer) menggunakan teknologi Laser presisi tinggi.

Download Modul
